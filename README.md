# 🎮 Pixel Ninja Flutter Game

A fast-paced 2D pixel platformer game developed using **Flutter** and the **Flame Game Engine**. Pixel Ninja delivers smooth gameplay, dynamic animations, real-time score tracking, and cloud-based features powered by Firebase.

---

## 🚀 Features

* 🕹️ Smooth character movement and physics-based gameplay
* 🎨 Pixel-art animations and immersive level design
* 🔥 Firebase Authentication (Google & Email Login)
* 🏆 Real-time leaderboard and score management
* ☁️ Cloud save and player progress synchronization
* 🎵 Integrated sound effects and responsive UI
* 📱 Cross-platform support for Android and iOS

---

## 🛠️ Technologies Used

* **Flutter**
* **Flame Engine**
* **Firebase Authentication**
* **Cloud Firestore**
* **Flutter Firebase Packages**

## 🎯 Core Gameplay

Players control a ninja character through challenging platformer levels filled with traps, enemies, collectibles, and checkpoints. The game includes realistic gravity, collision detection, jumping mechanics, and animated transitions for an engaging mobile gaming experience.

---

## 📸 Main Features

* Player movement and jump mechanics
* Collision detection system
* Multiple game levels
* Dynamic enemy and trap interactions
* Score collection system
* Leaderboard integration
* Game completion and progression system
* Profile and settings screens
